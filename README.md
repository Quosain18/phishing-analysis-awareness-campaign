# Phishing Analysis Awareness Campaign

**Project Overview:**
This project examines five suspicious email samples to understand phishing techniques, identify warning signs, and improve employee cybersecurity awareness.

**Email Samples Analyzed:**
1. Microsoft Account Security Alert
2. DHL Delivery Scam
3. Solar Panel Promotional Email
4. Tessa Dating Email
5. Amazon Account Suspension Scam

**Analysis Performed:**
• Email header inspection
• SPF, DKIM, and DMARC analysis
• Sender address and domain investigation
• Suspicious URL analysis using VirusTotal
• Social engineering identification
• Comparison of phishing warning signs

**Project Deliverables:**
• Phishing Analysis Report
• Phishing Awareness Poster
• Employee Phishing Safety Guide
• Phishing Awareness Quiz with Answer Key

**Tools Used:**
• ICANN Lookup
• VirusTotal
• Email header analysis
• Microsoft Word
• Canva

**Key Learning:**
Phishing attempts can use trusted brand names, urgent warnings, unfamiliar links, and deceptive requests. No single indicator proves whether an email is safe. Multiple warning signs should be examined together.
